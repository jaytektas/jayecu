    Knock¶

    Intermediate → Advanced

    In one sentence: after each cylinder fires, the ECU listens to the knock sensor in a short window, compares what it hears with what that cylinder normally sounds like at that speed and load, and pulls timing from a cylinder that is knocking — and it can spot pre-ignition and cut that cylinder's fuel.

    This chapter sets knock control up. Tuning the thresholds on a running engine is chapter 41.

    What it does¶

    Basic

    Knock (detonation) is part of the mixture exploding after the spark instead of burning smoothly. It rings the engine block at a frequency set mainly by the bore, and a knock sensor bolted to the block hears it. A little is harmless; sustained knock breaks pistons.

    The Knock Control module (knock):

    1. Listens to the knock sensor in a crank-angle window after each cylinder's top dead centre.
    2. Filters the signal to the knock frequency and measures its level in dB.
    3. Compares it with a learned noise floor: what that cylinder normally sounds like at that engine speed and load. How far above the floor it is — the intensity — is what counts.
    4. Retards the timing of a cylinder whose intensity goes over the Knock Threshold, a step at a time up to Max Retard, and gives the timing back slowly once it is quiet.
    5. Optionally detects pre-ignition (the mixture lighting before the spark) and cuts that cylinder's fuel.

    How it works¶

    Intermediate

    1 · Listening¶

    • Detection Source: Onboard samples KNOCK1 and KNOCK2 (CN4-23, CN4-22) directly. External reads a knock intensity in dB from another device over the bus (External Intensity); it has no per-cylinder detail, so it retards all cylinders together.

    • Window Start (before spark) (default 10°) and Window Duration (80°) set when to listen. The window opens that many degrees before each cylinder's own spark, so it follows the timing and the firing order: a 20° spark opens it at 30° BTDC, and it listens for 80° from there, to 50° after TDC. It opens before the spark so it can hear pre-ignition (below), and runs well past TDC because knock rings through the expansion stroke. It never opens earlier than 85° BTDC.

    • Knock Frequency: the centre of the filter. 0 (the default) works it out from the engine's Bore (chapter 15): 900 ÷ (π × bore/2) kHz — about 7.2 kHz for an 80 mm bore — or 7 kHz if no bore is set.

    • Per-Cylinder Knock Input: which sensor hears each cylinder. Auto takes it from the cylinder's bank (bank 1 → Knock 1, bank 2 → Knock 2). Sensor Gain trims one cylinder's level up or down, for a cylinder far from its sensor.

    The onboard sampling borrows the processor's third ADC from the AV13–AV16 inputs for each window and hands it back. Those four inputs keep reading, but update only between knock windows — at high engine speed on many cylinders the gaps get short.

    A window is sampled for at most 7.3 ms (2048 samples). At very low engine speed a long window is therefore cut short: a 40° window is only complete above about 900 RPM.

    2 · The learned noise floor¶

    For each cylinder the ECU keeps an 8 × 8 map of its normal noise, by engine speed and load. It learns only from clean cycles, and only when:

    • engine speed is above Noise Learn Min RPM (500);
    • the operating point has stayed in one cell for Noise Learn Dwell (200 ms);
    • fuel and spark are not being cut.

    A cell's first reading becomes its floor. Its next Fast-Learn Cycles (20) readings are averaged in fully, after which it follows slowly at Noise Learn Rate (0.05 per cycle). A knocking cycle never teaches the floor — otherwise the floor would chase the knock and the ECU would go deaf.

    A new engine is deaf until it has learned

    A cell that has never been learned cannot report knock — its first reading becomes the floor. After flashing, or on a new engine, drive gently through the speed and load range before loading the engine hard, so every cell you will use has a floor. Noise Floor Seed is only what the studio shows for an unlearned cell.

    The learned floor is saved on the SD card with the other learned tables (chapter 23), so the engine is not deaf after every start.

    3 · Knock and retard¶

    A measurement is knock when its intensity is above the Knock Threshold table (default 12 dB over the floor, by RPM and load). Each knock event adds Retard Step per Event (0.50°) to that cylinder's retard, up to the Max Knock Retard table (8°). The retard falls back at Retard Recovery Rate (1.00 °/s) once it stops. Each cylinder has its own retard with the onboard source; Knock Retard knock_retard shows the largest.

    While fuel is cut (overrun, a limiter, a protection) nothing is judged, and the retard recovers at the normal rate. Knock Suppress Below TPS (0 = off) adds a throttle gate if you need one.

    4 · Pre-ignition¶

    Pre-ignition lights the charge at or before the spark. The window always opens Window Start before each spark, so the energy before the spark is always in it, at any timing. With Pre-Ignition Detection on, a loud event is judged pre-ignition when either:

    • at least Pre-Spark Energy Fraction (35 %) of its energy came before the spark and it is Pre-Ignition Margin (6 dB) louder than the knock threshold; or
    • it is louder than Pre-Ignition Extreme Level (30 dB over the floor), whatever the timing.

    After Events Before Action (2) such events on one cylinder, the code P1790 + cylinder is set (severity 3) and that cylinder is cut: Cut Fuel on Pre-Ignition (on), and optionally Cut Spark (off by default — on wasted spark it also kills the partner cylinder). Pre-Ignition Cut Hold (0 = until the engine stops) says how long the cut lasts. Pre-ignition is not answered with retard: retarding does not stop it.

    5 · Sensor health¶

    A missing knock signal sets P1750 (Knock 1) or P1751 (Knock 2). A disconnected sensor still gives a reading — the input hears its own noise — so to catch one, turn on Detect a Quiet (Disconnected) Sensor and set Quiet Level from a log: the level at idle with the sensor plugged in, and with it unplugged.

    Before you start¶

    Basic

    • Knock sensors wired to KNOCK1/KNOCK2 with shielded cable and torqued to the maker's figure (chapter 11). The H1/H2 jumpers and the CN1 listening jack are in chapter 7.
    • Bore set on the engine page (chapter 15), for the knock frequency.
    • The cylinders' banks set (chapter 15), if you use Auto input selection on a V engine.
    • The trigger and ignition working (chapters 16 and 20).

    Setting it up¶

    Intermediate

    Open Configuration ▸ Ignition Tuning ▸ Knock Control and tick Enabled.

    1. Listening: Source Onboard; Knock Frequency 0 (from the bore); Window Start 10° before the spark, Duration 80°.
    2. Sensor per cylinder: leave on Auto, or set each cylinder to the sensor nearest it.
    3. Response: keep Retard Step 0.5° and Recovery 1 °/s.
    4. Learn the floor: drive gently through the range with the engine warm. Watch the Noise Floor page fill in (the Samples grid shows how many clean cycles taught each cell).
    5. Thresholds: tune them on a running engine — chapter 41.

    Worked examples¶

    Intermediate

    Example 1 — inline four, one sensor

    One sensor on Knock 1 between cylinders 2 and 3. Cylinders 1–4 on Knock 1 (Auto works if all four are bank 1). Sensor Gain +2 dB on cylinders 1 and 4, which are further from the sensor.

    Example 2 — V8, a sensor per bank

    Banks set in chapter 15; Auto sends bank 1 to Knock 1 and bank 2 to Knock 2.

    Example 3 — watching for pre-ignition on a boosted engine

    Window Start 10° before the spark, Duration 80°; Pre-Ignition Detection on, Events Before Action 2, Cut Fuel on, Cut Hold 0.

    Tuning it¶

    Advanced

    Chapter 41 covers threshold tuning with the Knock Scope, which shows each measurement against its cylinder's floor and threshold. In short: log knock_level, knock_count and knock_retard; raise the threshold where clean running trips it, and lower it where real knock (heard through the CN1 jack) goes unnoticed.

    Diagnostics¶

    Intermediate

    Code Meaning What sets it
    P1750 / P1751 Knock sensor 1 / 2 signal missing The sensor not reading, or reading quieter than Quiet Level (if enabled)
    P1752 Throttle signal missing Knock Suppress Below TPS is set and there is no throttle reading: detection is suppressed
    P1790–P179B Pre-ignition on cylinder 1–12 Events Before Action confirmed events (severity 3)

    Live channels: knock_level (the loudest recent measurement in dB, before the floor is taken off; it falls back at 20 dB/s), knock_count, knock_retard, knock_1, knock_2.

    Settings reference¶

    Setting What it does
    Knock Control Enabled
    knock.enabled
    Range: Off or On
    Default: Off    		 Listen for knock on the knock sensor input, judge each combustion event against a learned per-cylinder noise floor, and act on it. Off, no sampling is done at all — the ADC is not even re-tasked for it.
    Detection Source
    knock.source
    Range: one of: Onboard (ADC3 burst), External (bus signal)
    Default: Onboard (ADC3 burst)    		 Onboard: per-cylinder crank-angle-windowed ADC3 burst + DSP. The burst borrows ADC3 from the AV13-16 scan and hands it straight back, so those four inputs keep reading — but they update only between bursts, and on a many-cylinder engine at high rpm those gaps get short. External: a normalized intensity (dB) signal off the bus, which touches ADC3 not at all.
    Knock Frequency
    knock.knock_frequency
    Range: 0 to 25000
    Default: 0
    Units: Hz    		 Centre of the knock bandpass. 0 = derive it from the engine's Bore (900 / (pi x bore/2) kHz), or a generic 7 kHz if no bore is entered. A knocking cylinder rings at a frequency set by its bore, so a band in the wrong place is partly deaf to knock while looking configured.
    Window Start (before spark)
    knock.window_before_spark_deg
    Range: 0 to 60
    Default: 10
    Units: deg    		 How far BEFORE each cylinder's own spark its knock window opens, so the window follows the timing wherever it is: a 20 deg spark and 10 here opens it at 30 deg BTDC. It opens before the spark because pre-ignition lights the charge at or before it, and a window that opened after the spark could only hear knock. Never earlier than 85 deg BTDC (the point the window is armed from).
    Window Duration
    knock.window_length_deg
    Range: 1 to 180
    Default: 80
    Units: deg    		 How long the window listens, in crank degrees from where it opens. It opens before the spark, so it must run well past TDC to hear knock, which rings through the expansion stroke: the default 80 reaches 30-60 deg ATDC across 10-40 deg of advance. Longer lets in valve noise. At low RPM a long window can outlast the sample buffer; the rest is dropped and counted (knk).
    External Intensity Signal
    knock.external_intensity_sig
    Range: -1 to 32767
    Default: -1    		 source=External: the bus signal (dB) to threshold as the global knock level. Unassigned = none.
    Retard Step per Event
    knock.retard_step_deg
    Range: 0.00 to 10.00
    Default: 0.50
    Units: deg    		 How much timing is pulled per knocking event. It is a STEP, applied each time an event is judged as knock, so a persistently knocking cylinder walks back quickly while a single event costs one step. Too small and the retard cannot outrun the knock; too large and one false detection dumps a large chunk of timing.
    Retard Recovery Rate
    knock.retard_reapply_rate
    Range: 0.00 to 20.00
    Default: 1.00
    Units: deg/s    		 How fast the accumulated retard is given back once the knocking stops, in degrees per second. Slow is safe: it keeps a margin after the event rather than walking straight back into the condition that caused it. Fast recovers power sooner and risks a knock-retard-knock cycle.
    Knock Suppress Below TPS
    knock.suppress_min_tps
    Range: 0.0 to 100.0
    Default: 0.0
    Units: %    		 OPT-IN throttle gate; 0 = off, which is the default. Detection is already suppressed during overrun by wk::fuel_cut (DFCO), which is the precise "no combustion" condition, and the per-cylinder learned noise floor handles light-load mechanical noise by construction. Set this only if you want an additional throttle threshold — and note that on a drive-by-wire engine the ETB does idle control, so the plate sits at a few percent AT IDLE and a small value here will straddle the idle point.
    Noise Floor Seed
    knock.noise_seed_db
    Range: -60.0 to 20.0
    Default: -35.0
    Units: dB    		 The level shown for a cell that has never been learned. It does not judge anything: a cell with no learned samples cannot report knock at all, and its first reading taken while learning is allowed becomes its floor. So a fresh engine hears knock in a cell only after it has run there once, gently, with learning on.
    Noise Learn Rate
    knock.learn_rate
    Range: 0.000 to 1.000
    Default: 0.050    		 EMA weight applied to each clean cycle once a cell is established (0.05 = a cell follows a slow change over ~20 cycles). Higher tracks a changing engine faster and forgets a real noise floor faster.
    Fast-Learn Cycles
    knock.learn_fast_n
    Range: 0 to 200
    Default: 20    		 While a cell has fewer than this many clean samples it averages 1/n instead of the EMA rate, so a fresh cell converges in a few cycles rather than crawling up from the seed.
    Noise Learn Dwell
    knock.learn_dwell_ms
    Range: 0 to 5000
    Default: 200
    Units: ms    		 The operating point must sit in one cell this long before it learns — a transient sweeping across cells would otherwise smear one cell's noise into its neighbours.
    Detect a Quiet (Disconnected) Sensor
    knock.quiet_check_en
    Range: Off or On
    Default: Off    		 Report a knock sensor that reads too QUIET on a running engine. A disconnected sensor still produces a reading — the input samples its own noise — so it looks present and simply never hears knock. Off by default: set Quiet Level first.
    Quiet Level
    knock.quiet_db
    Range: -120.0 to 20.0
    Default: -60.0
    Units: dB    		 Below this level for a second, with the engine running above the learn floor, the sensor is reported as missing. Set it from a log: the knock level at idle with the sensor connected, and again with it unplugged — put this between the two, nearer the unplugged reading.
    Noise Learn Min RPM
    knock.learn_min_rpm
    Range: 0 to 10000
    Default: 500
    Units: RPM    		 Below this the engine is cranking or stalling and the background is not representative.
    Pre-Ignition Detection
    knock.preign_enabled
    Range: Off or On
    Default: Off    		 Needs a window that opens BEFORE the spark (negative Window Start) — with an ATDC-only window there is nothing to see.
    Pre-Spark Energy Fraction
    knock.preign_pre_frac
    Range: 0 to 100
    Default: 35
    Units: %    		 How much of the window's energy must sit BEFORE the spark to call it pre-ignition. Normal combustion puts almost none there.
    Pre-Ignition Margin
    knock.preign_margin_db
    Range: 0.0 to 60.0
    Default: 6.0
    Units: dB    		 How far above the KNOCK threshold the event must also be. Pre-ignition is violent; this keeps ordinary knock with a little pre-spark leakage from being reported as one.
    Pre-Ignition Extreme Level
    knock.preign_extreme_db
    Range: 0.0 to 90.0
    Default: 30.0
    Units: dB    		 Intensity over the noise floor above which an event is treated as pre-ignition REGARDLESS of phase. Fail toward the protective response: if we cannot tell, cutting is the safe error.
    Events Before Action
    knock.preign_events_to_act
    Range: 1 to 50
    Default: 2    		 Confirmed events on one cylinder before the DTC is raised and the cut applied. 1 acts on a single event; higher rides out a lone false positive.
    Cut Fuel on Pre-Ignition
    knock.preign_cut_fuel
    Range: Off or On
    Default: On    		 Cut the offending cylinder's injector. The correct protective action — and on a wasted-spark engine the only one that isolates a single cylinder, since two share a coil.
    Cut Spark on Pre-Ignition
    knock.preign_cut_spark
    Range: Off or On
    Default: Off    		 Also cut the cylinder's coil. On wasted spark this necessarily kills its companion cylinder's spark too, so it is off by default.
    Pre-Ignition Cut Hold
    knock.preign_clear_s
    Range: 0 to 3600
    Default: 0
    Units: s    		 Seconds of silence before a cut cylinder is restored. 0 = latch until engine stop, which is the conservative choice for a fault that destroys pistons.
    Knock Threshold (over noise floor) X Channel
    knock.knock_threshold_table_x_src
    Range: -1 to 32767
    Default: 319    		 WHICH SIGNAL the X axis of 'Knock Threshold (over noise floor)' is looked up on. The axis holds the breakpoints; this says what is compared against them, so changing it re-points the table at a different quantity without moving a single cell — and the breakpoints, chosen for the old signal's range and units, will almost certainly need redrawing.

    Default: 125    		 WHICH SIGNAL the Y axis of 'Knock Threshold (over noise floor)' is looked up on.     Knock Threshold (over noise floor)
    knock.knock_threshold_table
    Range: 0.0 to 60.0
    Default: 8 × 8 table
    Units: dB    		 How far ABOVE the learned noise floor a measurement has to be before it counts as knock, per RPM and load. It is a margin, not an absolute level, which is what makes it portable: the floor already carries the engine's own mechanical noise at that operating point, so this number is purely how much louder than normal is abnormal. Too low and mechanical noise reads as knock; too high and real knock passes unremarked.
    Max Knock Retard
    knock.knock_max_retard_table
    Range: 0.0 to 30.0
    Default: 8 × 8 table
    Units: deg    		 The most timing knock control may pull at each RPM and load, whatever it hears. It is the floor under the authority: it bounds how far a runaway detection — a loose sensor, a noisy accessory — can retard the engine, and it stops the controller from retarding into a condition worse than the knock it was chasing.
    Knock RPM Axis
    knock.knock_rpm_axis
    Range: 0 to 0
    Default: 8-point curve
    Units: RPM    		 The RPM breakpoints the knock threshold and max-retard tables are looked up on. Knock sensitivity is strongly RPM-dependent, because both the engine's noise and its knock frequency move with speed — concentrate breakpoints where the engine actually spends its time under load.
    Knock Load Axis
    knock.knock_load_axis
    Range: 0 to 0
    Default: 8-point curve
    Units: kPa    		 The load breakpoints for the knock tables. Knock is a load phenomenon above all, so this axis is what lets a cruise cell be judged differently from a full-throttle one; it matches the load axis the ignition tables use so the two are read at the same operating point.
