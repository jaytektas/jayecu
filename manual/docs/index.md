# jayecu User Manual

The manual for the **jayecu** engine control unit and **jayecu Studio**, the program you use to set it
up, tune it and watch it run.

It takes you from a new board to a tuned engine, and it is the reference you come back to when
something does not behave the way you expect. Everything in it is taken from the firmware and the
studio themselves — settings, ranges, defaults and behaviour — and the reference section is generated
from the same definition the studio loads.

## How it is written

- Each section is marked **Basic**, **Intermediate** or **Advanced**, so you can skip what you do
  not need yet ([chapter 1](part1/01-using-this-manual.md)).
- Every chapter about an ECU function has the same shape: what it does, how it works, before you
  start, setting it up, worked examples, tuning, diagnostics, troubleshooting, and every setting.
- Warnings marked **danger** are about damage to the engine or to people. Read them.

!!! tip "The manual is inside the studio"
    **Help ▸ User Manual** (<kbd>F1</kbd>) opens this manual from the copy installed with the
    studio, with no internet connection needed.
