    Output channels¶

    Every channel the ECU sends to the studio, grouped as the studio groups them. The name is what you type in an expression (chapter 34), a Lua script (chapter 35), a CAN field (chapter 33) or a log. Logged marks the channels in the ECU's default onboard-log set (chapter 42).

    516 channels.
