    Knock settings¶

    Setting What it does
    Knock Control Enabled
    knock.enabled
    Range: Off or On
    Default: Off    		 Listen for knock on the knock sensor input, judge each combustion event against a learned per-cylinder noise floor, and act on it. Off, no sampling is done at all — the ADC is not even re-tasked for it.
    Detection Source
    knock.source
    Range: one of: Onboard (ADC3 burst), External (bus signal)
    Default: Onboard (ADC3 burst)    		 Onboard: per-cylinder crank-angle-windowed ADC3 burst + DSP. The burst borrows ADC3 from the AV13-16 scan and hands it straight back, so those four inputs keep reading — but they update only between bursts, and on a many-cylinder engine at high rpm those gaps get short. External: a normalized intensity (dB) signal off the bus, which touches ADC3 not at all.
    Knock Frequency
    knock.knock_frequency
    Range: 0 to 25000
    Default: 0
    Units: Hz    		 Centre of the knock bandpass. 0 = derive it from the engine's Bore (900 / (pi x bore/2) kHz), or a generic 7 kHz if no bore is entered. A knocking cylinder rings at a frequency set by its bore, so a band in the wrong place is partly deaf to knock while looking configured.
    Window Start (before spark)
    knock.window_before_spark_deg
    Range: 0 to 60
    Default: 10
    Units: deg    		 How far BEFORE each cylinder's own spark its knock window opens, so the window follows the timing wherever it is: a 20 deg spark and 10 here opens it at 30 deg BTDC. It opens before the spark because pre-ignition lights the charge at or before it, and a window that opened after the spark could only hear knock. Never earlier than 85 deg BTDC (the point the window is armed from).
    Window Duration
    knock.window_length_deg
    Range: 1 to 180
    Default: 80
    Units: deg    		 How long the window listens, in crank degrees from where it opens. It opens before the spark, so it must run well past TDC to hear knock, which rings through the expansion stroke: the default 80 reaches 30-60 deg ATDC across 10-40 deg of advance. Longer lets in valve noise. At low RPM a long window can outlast the sample buffer; the rest is dropped and counted (knk).
    External Intensity Signal
    knock.external_intensity_sig
    Range: -1 to 32767
    Default: -1    		 source=External: the bus signal (dB) to threshold as the global knock level. Unassigned = none.
    Retard Step per Event
    knock.retard_step_deg
    Range: 0.00 to 10.00
    Default: 0.50
    Units: deg    		 How much timing is pulled per knocking event. It is a STEP, applied each time an event is judged as knock, so a persistently knocking cylinder walks back quickly while a single event costs one step. Too small and the retard cannot outrun the knock; too large and one false detection dumps a large chunk of timing.
    Retard Recovery Rate
    knock.retard_reapply_rate
    Range: 0.00 to 20.00
    Default: 1.00
    Units: deg/s    		 How fast the accumulated retard is given back once the knocking stops, in degrees per second. Slow is safe: it keeps a margin after the event rather than walking straight back into the condition that caused it. Fast recovers power sooner and risks a knock-retard-knock cycle.
    Knock Suppress Below TPS
    knock.suppress_min_tps
    Range: 0.0 to 100.0
    Default: 0.0
    Units: %    		 OPT-IN throttle gate; 0 = off, which is the default. Detection is already suppressed during overrun by wk::fuel_cut (DFCO), which is the precise "no combustion" condition, and the per-cylinder learned noise floor handles light-load mechanical noise by construction. Set this only if you want an additional throttle threshold — and note that on a drive-by-wire engine the ETB does idle control, so the plate sits at a few percent AT IDLE and a small value here will straddle the idle point.
    Noise Floor Seed
    knock.noise_seed_db
    Range: -60.0 to 20.0
    Default: -35.0
    Units: dB    		 The level shown for a cell that has never been learned. It does not judge anything: a cell with no learned samples cannot report knock at all, and its first reading taken while learning is allowed becomes its floor. So a fresh engine hears knock in a cell only after it has run there once, gently, with learning on.
    Noise Learn Rate
    knock.learn_rate
    Range: 0.000 to 1.000
    Default: 0.050    		 EMA weight applied to each clean cycle once a cell is established (0.05 = a cell follows a slow change over ~20 cycles). Higher tracks a changing engine faster and forgets a real noise floor faster.
    Fast-Learn Cycles
    knock.learn_fast_n
    Range: 0 to 200
    Default: 20    		 While a cell has fewer than this many clean samples it averages 1/n instead of the EMA rate, so a fresh cell converges in a few cycles rather than crawling up from the seed.
    Noise Learn Dwell
    knock.learn_dwell_ms
    Range: 0 to 5000
    Default: 200
    Units: ms    		 The operating point must sit in one cell this long before it learns — a transient sweeping across cells would otherwise smear one cell's noise into its neighbours.
    Detect a Quiet (Disconnected) Sensor
    knock.quiet_check_en
    Range: Off or On
    Default: Off    		 Report a knock sensor that reads too QUIET on a running engine. A disconnected sensor still produces a reading — the input samples its own noise — so it looks present and simply never hears knock. Off by default: set Quiet Level first.
    Quiet Level
    knock.quiet_db
    Range: -120.0 to 20.0
    Default: -60.0
    Units: dB    		 Below this level for a second, with the engine running above the learn floor, the sensor is reported as missing. Set it from a log: the knock level at idle with the sensor connected, and again with it unplugged — put this between the two, nearer the unplugged reading.
    Noise Learn Min RPM
    knock.learn_min_rpm
    Range: 0 to 10000
    Default: 500
    Units: RPM    		 Below this the engine is cranking or stalling and the background is not representative.
    Pre-Ignition Detection
    knock.preign_enabled
    Range: Off or On
    Default: Off    		 Needs a window that opens BEFORE the spark (negative Window Start) — with an ATDC-only window there is nothing to see.
    Pre-Spark Energy Fraction
    knock.preign_pre_frac
    Range: 0 to 100
    Default: 35
    Units: %    		 How much of the window's energy must sit BEFORE the spark to call it pre-ignition. Normal combustion puts almost none there.
    Pre-Ignition Margin
    knock.preign_margin_db
    Range: 0.0 to 60.0
    Default: 6.0
    Units: dB    		 How far above the KNOCK threshold the event must also be. Pre-ignition is violent; this keeps ordinary knock with a little pre-spark leakage from being reported as one.
    Pre-Ignition Extreme Level
    knock.preign_extreme_db
    Range: 0.0 to 90.0
    Default: 30.0
    Units: dB    		 Intensity over the noise floor above which an event is treated as pre-ignition REGARDLESS of phase. Fail toward the protective response: if we cannot tell, cutting is the safe error.
    Events Before Action
    knock.preign_events_to_act
    Range: 1 to 50
    Default: 2    		 Confirmed events on one cylinder before the DTC is raised and the cut applied. 1 acts on a single event; higher rides out a lone false positive.
    Cut Fuel on Pre-Ignition
    knock.preign_cut_fuel
    Range: Off or On
    Default: On    		 Cut the offending cylinder's injector. The correct protective action — and on a wasted-spark engine the only one that isolates a single cylinder, since two share a coil.
    Cut Spark on Pre-Ignition
    knock.preign_cut_spark
    Range: Off or On
    Default: Off    		 Also cut the cylinder's coil. On wasted spark this necessarily kills its companion cylinder's spark too, so it is off by default.
    Pre-Ignition Cut Hold
    knock.preign_clear_s
    Range: 0 to 3600
    Default: 0
    Units: s    		 Seconds of silence before a cut cylinder is restored. 0 = latch until engine stop, which is the conservative choice for a fault that destroys pistons.
    Knock Threshold (over noise floor) X Channel
    knock.knock_threshold_table_x_src
    Range: -1 to 32767
    Default: 319    		 WHICH SIGNAL the X axis of 'Knock Threshold (over noise floor)' is looked up on. The axis holds the breakpoints; this says what is compared against them, so changing it re-points the table at a different quantity without moving a single cell — and the breakpoints, chosen for the old signal's range and units, will almost certainly need redrawing.

    Knock Threshold (over noise floor)
    knock.knock_threshold_table
    Range: 0.0 to 60.0
    Default: 8 × 8 table
    Units: dB    		 How far ABOVE the learned noise floor a measurement has to be before it counts as knock, per RPM and load. It is a margin, not an absolute level, which is what makes it portable: the floor already carries the engine's own mechanical noise at that operating point, so this number is purely how much louder than normal is abnormal. Too low and mechanical noise reads as knock; too high and real knock passes unremarked.
    Max Knock Retard
    knock.knock_max_retard_table
    Range: 0.0 to 30.0
    Default: 8 × 8 table
    Units: deg    		 The most timing knock control may pull at each RPM and load, whatever it hears. It is the floor under the authority: it bounds how far a runaway detection — a loose sensor, a noisy accessory — can retard the engine, and it stops the controller from retarding into a condition worse than the knock it was chasing.
    Knock RPM Axis
    knock.knock_rpm_axis
    Range: 0 to 0
    Default: 8-point curve
    Units: RPM    		 The RPM breakpoints the knock threshold and max-retard tables are looked up on. Knock sensitivity is strongly RPM-dependent, because both the engine's noise and its knock frequency move with speed — concentrate breakpoints where the engine actually spends its time under load.
    Knock Load Axis
    knock.knock_load_axis
    Range: 0 to 0
    Default: 8-point curve
    Units: kPa    		 The load breakpoints for the knock tables. Knock is a load phenomenon above all, so this axis is what lets a cruise cell be judged differently from a full-throttle one; it matches the load axis the ignition tables use so the two are read at the same operating point.
