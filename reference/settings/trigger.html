    Trigger settings¶

    Setting What it does
    Trigger Offset BTDC
    trigger.trigger_offset_btdc
    Range: -720.0 to 720.0
    Default: 0.0
    Units: deg    		 Crank angle from the trigger's reference point to TDC #1: POSITIVE means the reference occurs that many degrees BTDC #1, NEGATIVE means ATDC. The reference is the FIRST TOOTH AFTER SYNC — on a missing-tooth wheel that is the tooth ending the gap, the only event the decoder can identify. A 2JZ 36-2 is 155°. This is the ONE place the wheel-to-engine relationship is set — per-cylinder TDC angles are then plain engine angles (cyl 1 = 0).
    Pickup Angle
    trigger.sensor_angle
    Range: -360.0 to 360.0
    Default: 0.0
    Units: deg    		 Where the trigger pickup sits: degrees from vertical, positive ANTICLOCKWISE (to the left), seen from the front of the engine. A 2JZ is +105. DISPLAY ONLY — the ECU stores it so the studio can draw its trigger setup as you actually see it, and never acts on it. Timing comes from Trigger Offset BTDC alone.
    Min RPM for Full (PHASE) Sync
    trigger.min_full_sync_rpm_x10
    Range: 0.0 to 25000.0
    Default: 0.0
    Units: RPM    		 Lower edge of the rpm band in which the phase (cam) stream is trusted to ACQUIRE full sync. Below it the cam is ignored for acquisition — only crank (360°) sync is taken — but an already-locked phase is RETAINED on crank counting as rpm falls (e.g. back to idle). For a VR cam sensor (MAX9924) set ~1500: below that its auto-threshold reset glitches a single cam tooth. 0 with Max also 0 disables the band (phase acquired whenever the cam locks).
    Max RPM for Full (PHASE) Sync
    trigger.max_full_sync_rpm_x10
    Range: 0.0 to 25000.0
    Default: 0.0
    Units: RPM    		 Upper edge of the phase-acquisition band. Above it the cam stream is ignored for acquisition (retention unaffected). 0 = no upper bound. With both Min and Max 0 the band is disabled.
    Stream Enabled
    trigger.streams[].enabled
    Range: Off or On
    Default: Off    		 Whether this role is present on the engine. THE liveness rule — a disabled stream is not bound, not decoded, and holds no pin. Slots are independent: an engine with phasers on both intakes enables Cam Intake B1 and Cam Intake B2 and leaves the exhaust slots off. Applies to each of: Crank Primary, Crank Secondary, Cam Intake B1, Cam Exhaust B1, Cam Intake B2, Cam Exhaust B2.
    Pattern Repeats / Cycle
    trigger.streams[].repeats
    Range: 0 to 24
    Default: 0    		 How many times this stream's pattern repeats per ENGINE CYCLE; its angular period is cycle/repeats. 0 takes the default from the slot — 2 for a crank slot on a four-stroke, 1 for a cam slot. State it when the wheel is neither: a symmetrical crank pattern that appears twice per revolution is 4, a 12-tooth Honda crank is 24, and a distributor on an ODD-cylinder engine is its cylinder count (5 pulses per cycle is 2.5 per revolution, which no crank-rate wheel can express). Applies to each of: Crank Primary, Crank Secondary, Cam Intake B1, Cam Exhaust B1, Cam Intake B2, Cam Exhaust B2.
    Capture Input
    trigger.streams[].capture_index
    Range: one of: None, VR1, VR2, DIG1, DIG2, DIG3, DIG4, DIG5, DIG6, DIG7, DIG8
    Default: set per element    		 WHICH PHYSICAL INPUT this stream arrives on, as an index into the board's capture pool. The list comes from the board's own TRIGGER_INPUT capability group, so the name you pick IS the pool index (VR1=0, VR2=1, DIG1=2 …) and nothing maps between them. It says where the signal enters; the stream's INDEX, not this, says what role it plays. Applies to each of: Crank Primary, Crank Secondary, Cam Intake B1, Cam Exhaust B1, Cam Intake B2, Cam Exhaust B2.
    Capture Edge
    trigger.streams[].edge
    Range: one of: Rising, Falling, Both
    Default: Rising    		 Which edge of this input the capture takes. A GAP or SEQUENCE stream counts EVERY event it is handed, so Both doubles the events per tooth and the pattern must then be described in those terms — it is not a way to be more tolerant. Only the edges selected here are captured or believed, for every pattern: pick the edges the signal makes reliably. A VR input (MAX9924) makes its RISING edge at the zero crossing and its falling edge wherever a threshold re-armed from the last pulse lands, so on VR choose Rising. A WIDTH stream on Rising or Falling takes every selected edge as its reference (one pulse per cycle; nothing can measure a width from one edge, so WIDTH min/max are not applied); on Both it measures the width between the edges and uses it to pick out the reference, timed from the rising edge. Applies to each of: Crank Primary, Crank Secondary, Cam Intake B1, Cam Exhaust B1, Cam Intake B2, Cam Exhaust B2.
    Primitive
    trigger.streams[].primitive
    Range: one of: Gap, Sequence, Width
    Default: Gap    		 Which matcher decodes this stream. GAP is a uniform wheel of Base Teeth with zero or more missing-tooth gaps at known positions — it subsumes the even/distributor wheel (no gaps, relative lock only), the single missing tooth, and multi-gap patterns. SEQUENCE is an explicit list of inter-event angles, for a pattern no uniform wheel describes: an odd-fire crank, or a cam's group of unevenly spaced pulses. WIDTH identifies by PULSE LENGTH — one pulse whose angular width falls inside the WIDTH band anchors the stream, every other pulse is ignored. Applies to each of: Crank Primary, Crank Secondary, Cam Intake B1, Cam Exhaust B1, Cam Intake B2, Cam Exhaust B2.
    Base Teeth (GAP)
    trigger.streams[].slots
    Range: 0 to 3600
    Default: 0    		 GAP only. The BASE tooth count — what the wheel would have if nothing were missing — so a 60-2 is 60 and a 36-1 is 36, NOT 58 and 35. Tooth pitch is the stream's angular period divided by this. The present-tooth count the decoder actually walks is derived, not entered: slots minus the sum of (Gap Ratio − 1) over every gap. Applies to each of: Crank Primary, Crank Secondary, Cam Intake B1, Cam Exhaust B1, Cam Intake B2, Cam Exhaust B2.
    Gap Ratio (GAP, missing+1)
    trigger.streams[].gap_ratio
    Range: 1 to 16
    Default: 2    		 GAP only. How many tooth pitches ONE gap spans, which is the number of missing teeth plus one: a 36-1 is 2, a 60-2 is 3. 0 is read as 2. It applies to every gap in this stream, so a wheel whose gaps differ in size is not a GAP wheel — describe it as a SEQUENCE. Applies to each of: Crank Primary, Crank Secondary, Cam Intake B1, Cam Exhaust B1, Cam Intake B2, Cam Exhaust B2.
    Cell Length (gaps / steps)
    trigger.streams[].cell_len
    Range: 0 to 96
    Default: 0    		 How many of this stream's 96 cells are LIVE. What they MEAN depends on the primitive. GAP: each cell is the PRESENT-TOOTH INDEX of the tooth that ENDS one gap (counting only teeth that exist, from 0; the first gap is always 0, because the tooth after it is the reference), so the length is the gap count — the decoder reads at most 8. SEQUENCE: each cell is one INTER-EVENT ANGLE in 0.1° — the step from one event to the next, not an absolute position — so the length is the pattern's event count, up to all 96. WIDTH uses no cells. Applies to each of: Crank Primary, Crank Secondary, Cam Intake B1, Cam Exhaust B1, Cam Intake B2, Cam Exhaust B2.
    Match Window (±)
    trigger.streams[].window_pct
    Range: 0 to 99
    Default: 25
    Units: %    		 Match tolerance AT SPEED, as ± percent of one TOOTH PITCH — not of the interval, which is the same thing for a normal tooth and a very different thing at a gap. 50 means a valid tooth lands between half and one and a half pitches of where it was due, which is the same 1.5× that defines a gap, so the acceptance band and the gap rule share one boundary. Tighter rejects a marginal wheel sooner; looser rides through more before it stops trusting the position. 0 is read as 50. Applies to each of: Crank Primary, Crank Secondary, Cam Intake B1, Cam Exhaust B1, Cam Intake B2, Cam Exhaust B2.
    Match Window at Cranking (±)
    trigger.streams[].window_crank_pct
    Range: 0 to 99
    Default: 75
    Units: %    		 The same tolerance while CRANKING, blended into the running one as the engine picks up. A starter turns an engine unevenly — it slows into every compression and surges over the top — so tooth-to-tooth speed swings hardest exactly where the decoder has the least history to predict from. At 6000 rpm the rotating inertia makes consecutive teeth almost identical and a tight band is free. One number cannot serve both: tight enough to catch a marginal wheel at speed is tight enough to stop the engine ever starting. 0 is read as the running value, which disables the blend. Applies to each of: Crank Primary, Crank Secondary, Cam Intake B1, Cam Exhaust B1, Cam Intake B2, Cam Exhaust B2.
    WIDTH min
    trigger.streams[].width_min
    Range: 0.0 to 720.0
    Default: 0.0
    Units: deg    		 WIDTH only, and only with Edge = Both (a width needs both edges to be reliable; on Rising or Falling every selected edge is the reference). The narrowest pulse, in degrees of stream angle, that counts as THE reference. Width is measured as an ANGLE rather than a time, so one band holds across the rev range. A pulse outside [min, max] is ignored outright — it neither anchors nor breaks an existing lock — so the band wants to be wide enough for real jitter and narrow enough to exclude every other pulse on the wheel. Applies to each of: Crank Primary, Crank Secondary, Cam Intake B1, Cam Exhaust B1, Cam Intake B2, Cam Exhaust B2.
    WIDTH max
    trigger.streams[].width_max
    Range: 0.0 to 720.0
    Default: 0.0
    Units: deg    		 WIDTH only. The widest pulse, in degrees of stream angle, that counts as the reference. See WIDTH min: the pair is a band, and anything outside it is discarded rather than treated as a bad match. Applies to each of: Crank Primary, Crank Secondary, Cam Intake B1, Cam Exhaust B1, Cam Intake B2, Cam Exhaust B2.
    WIDTH target angle
    trigger.streams[].width_target
    Range: 0.0 to 720.0
    Default: 0.0
    Units: deg    		 WIDTH only. The angle of the reference pulse's LEADING edge in this stream. The width is only known when the pulse ends, so the ECU anchors at the trailing edge, at this angle plus the measured width. A width match is an ABSOLUTE reference: nothing derives this number, the decoder simply takes it, so it alone positions the stream. Measure it on the engine; a guess here mis-phases everything downstream by exactly its error. Applies to each of: Crank Primary, Crank Secondary, Cam Intake B1, Cam Exhaust B1, Cam Intake B2, Cam Exhaust B2.
    Cam Nominal Angle (VVT)
    trigger.streams[].nominal_angle
    Range: 0.0 to 720.0
    Default: 0.0
    Units: deg    		 Cam slots only. The angle this cam's reference sits at with the phaser HOME (parked on its stop: fully retarded for a typical intake, fully advanced for a typical exhaust). The reported cam angle is how far the cam has moved from here, in degrees of ADVANCE (positive = earlier, negative = retarded), wrapped into ±360°. It is also what the sync-position check measures against, so on a PHASED cam it must be right — see Cam Is Phased. Applies to each of: Crank Primary, Crank Secondary, Cam Intake B1, Cam Exhaust B1, Cam Intake B2, Cam Exhaust B2.
    Cam Is Phased (VVT)
    trigger.streams[].phased
    Range: Off or On
    Default: Off    		 Whether a phaser can move this cam relative to the crank. It changes two things and both matter. A phased cam CANNOT ANCHOR a crank that has no unique feature of its own — a phaser is a controlled variable, not a reference — so an even-tooth crank with only a phased cam can never know where it is, and the tune is refused rather than run. And the sync-position check has to allow the phaser its travel: on a fixed cam the reference must land within a tooth of its nominal angle, on a phased one it is expected to move by design, and checking it against a fixed position would drop phase continuously on a perfectly healthy VVT engine. Applies to each of: Crank Primary, Crank Secondary, Cam Intake B1, Cam Exhaust B1, Cam Intake B2, Cam Exhaust B2.
    Phaser Authority
    trigger.streams[].phase_authority
    Range: 0.0 to 180.0
    Default: 60.0
    Units: deg    		 How far, in CRANK degrees, the phaser can move this cam away from its nominal (parked) angle. Only read when Cam Is Phased. The sync-position check allows ± this much: a cam found outside it has not been moved by the phaser, it has moved because something mechanical did — a stretched or jumped chain. Set it to the phaser's real travel; too large blinds the check, too small drops phase at full authority. The band is symmetric on purpose even though a phaser parks at one end, so that a tune does not have to state which direction its cam travels and cannot fault a healthy engine by getting that backwards. Applies to each of: Crank Primary, Crank Secondary, Cam Intake B1, Cam Exhaust B1, Cam Intake B2, Cam Exhaust B2.
    Cam Mechanical Allowance
    trigger.streams[].phase_allowance
    Range: 0.0 to 180.0
    Default: 0.0
    Units: deg    		 FIXED cams only (a phased one is bounded by Phaser Authority instead). How far this cam may sit from its nominal angle for mechanical reasons the trigger layer cannot derive — chain stretch, gear lash, torsional wind-up under load. The sync-position check allows the LARGER of this and the decoder's own measurement floor, so raising it only ever widens the band and 0 (the default) leaves the check exactly as tight as the decoder can measure. It is separate from Phaser Authority because the two bound different things: authority is travel the ECU commands, allowance is slop it does not. Widen it if a healthy engine drops phase under load; do not widen it to silence a fault that appears suddenly, which is what a jumped chain looks like. Applies to each of: Crank Primary, Crank Secondary, Cam Intake B1, Cam Exhaust B1, Cam Intake B2, Cam Exhaust B2.
    Cell value
    trigger.streams[].cell[96].v
    Range: 0 to 7200    		 One cell of THIS stream's run, read only while its index is below Cell Length. Its meaning is set by the stream's primitive: for GAP it is the PRESENT-TOOTH INDEX of the tooth that ENDS one gap, for SEQUENCE it is one INTER-EVENT ANGLE in 0.1° — the step to the next event, not a position. WIDTH reads no cells at all. Cells past Cell Length are ignored, not cleared, so shrinking a pattern leaves the old values in place.
