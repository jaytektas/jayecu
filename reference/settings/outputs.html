    Outputs settings¶

    Setting What it does
    Function
    outputs.output[].function
    Range: one of: None, Ignition, Injector, Generic
    Default: None    		 What this pin does. NONE leaves it undriven (high impedance). IGNITION fires a coil for the cylinder below, and only an IGN pin can do it; INJECTOR opens an injector for the cylinder below in its stage, and only an LS pin can. GENERIC is an output driven by its own conditions and value — a fuel pump, a fan, a tachometer. A coil or injector change applies at the next engine stop, like any firing change.
    Cylinder
    outputs.output[].cylinder
    Range: one of: None, Cylinder 1, Cylinder 2, Cylinder 3, Cylinder 4, Cylinder 5, Cylinder 6, Cylinder 7, Cylinder 8, Cylinder 9, Cylinder 10, Cylinder 11, Cylinder 12, All Cylinders, Bank 1, Bank 2
    Default: None    		 The cylinder this coil or injector serves. On WASTED SPARK a coil names one cylinder and also fires its companion, whichever the firing order makes that. ALL CYLINDERS is a distributor coil, or a multi-point injector. BANK 1 / BANK 2 is an injector shared by every cylinder on that bank. On a rotary the number is the rotor.
    Injection Stage
    outputs.output[].inj_stage
    Range: one of: Stage 1, Stage 2, Stage 3, Stage 4
    Default: Stage 1    		 Which injection stage this injector belongs to: Stage 1 is the primary, Stages 2-4 the staged secondaries — the same stages Fuel Tuning names. The stage's mode (Fuel System) decides how its injectors fire, and a row in a stage beyond Number of Injection Stages is ignored.
    Plug
    outputs.output[].ign_plug
    Range: one of: Leading, Trailing
    Default: Leading    		 Rotary only: whether this coil fires the rotor's leading or trailing plug. A piston engine ignores it.
    Kind
    outputs.output[].kind
    Range: one of: PWM, Digital
    Default: PWM    		 PWM drives a duty cycle at the configured frequency; DIGITAL drives a plain on/off level. Choose by what is on the other end: a solenoid being modulated wants PWM, a relay or a lamp wants digital, and driving a relay with PWM buzzes it.
    Active High
    outputs.output[].active_high
    Default: 1    		 Which electrical level means ON — for every function, a coil (ON = dwell) and an injector (ON = open) included. Active-high asserts by driving the pin high; active-low asserts by pulling it low, which is what a load wired to +12V through a low-side driver needs. Getting it backwards inverts the output — the actuator is then energised whenever it should be idle, including at reset.
    PWM Frequency
    outputs.output[].pwm_freq_hz
    Default: 250
    Units: Hz    		 Carrier frequency for a PWM output. It is set by the load, not by preference: a solenoid wants a frequency low enough to move but high enough not to buzz, a heater wants low, and a valve driven too fast simply sees an average and stops responding at all.
    Primary Policy
    outputs.output[].primary_policy
    Range: one of: First, Average, Minimum, Maximum
    Default: First    		 How to combine several valid PRIMARY candidates into one value. FIRST takes the first valid one in order and is the plain choice. AVG blends them. MIN and MAX take an extreme — MIN being the conservative one, since it lets any contributing module hold the output down. It has no effect when only one primary is ever valid.
    Candidate Count
    outputs.output[].n_cand
    Default: 0    		 How many of the four candidate slots are in use. Candidates are read in order, and their ROLES compose a fixed precedence: primaries make the request, limits clamp it down, and the first valid override replaces everything. That is what separates a plain knob from a knob a safety limiter can cap and an override can veto.
    Scale (x1000)
    outputs.output[].scale_x1000
    Default: 1000    		 Multiplier applied to the arbitrated engineering value on its way to the actuator command, expressed in thousandths (1000 = ×1). With the offset it is the unit conversion between what the module means and what the hardware takes.
    Offset (x10)
    outputs.output[].offset_x10
    Default: 0    		 Constant added after scaling, in tenths. Together with the scale it maps an engineering range onto an actuator range — the pair is a straight line, so two known points are enough to determine both.
    Clamp Lo (x10)
    outputs.output[].clamp_lo_x10
    Default: 0    		 Lower bound on the final command, in tenths, applied after scale and offset. It is the actuator's own limit, not a control decision: a valve that must never be commanded fully shut is held off its stop here rather than trusting every producer upstream to remember.
    Clamp Hi (x10)
    outputs.output[].clamp_hi_x10
    Default: 1000    		 Upper bound on the final command, in tenths. Same purpose as the low clamp — the last defence, past every module, that the hardware is never asked for more than it can take.
    Failsafe (x10)
    outputs.output[].failsafe_x10
    Default: 0    		 The command emitted when NO candidate signal is valid, in tenths — a dead bus, a crashed producer, a module that never started. Arbitration always emits something rather than nothing, and this is that something, so the choice matters: it is the state the actuator is driven to when the software has stopped having an opinion.
    Turn On When
    outputs.output[].on_expr    		 The condition that turns this output ON. Empty means the slot is driven by its candidate value alone, exactly as before. Reads any bus channel and any config setting: "clt > 95" for a fan, "key_on_s < 3 or age(trigger_teeth) < 1500" for a fuel pump (prime, then run while the wheel turns).
    Turn Off When
    outputs.output[].off_expr    		 The condition that turns it OFF again. Empty means "when Turn On When stops being true", which is right for a plain switch; a separate condition is how hysteresis is written — on above 95, off below 90 — and it is the difference between a fan that settles and one that chatters at the threshold.
    Duty Expression
    outputs.output[].duty_expr    		 The commanded value, computed. Used when Value From is EXPRESSION; the number the program returns IS the duty (before scale, offset and the clamps). A program that cannot be answered leaves the output at its failsafe, exactly as a dead candidate does.
    Frequency From
    outputs.output[].freq_source
    Range: one of: Fixed, Table, Expression
    Default: Fixed    		 Where the PWM carrier comes from. FIXED is the frequency below and is what almost every load wants. TABLE and EXPRESSION exist because some do not: a stepper-style valve swept over its range, a horn or buzzer whose pitch is the output, an injector-style solenoid whose carrier follows engine speed. Digital outputs ignore this entirely.
    Frequency Expression
    outputs.output[].freq_expr    		 The carrier frequency in Hz, computed. Used when Frequency From is EXPRESSION. Clamped to the same 1..50000 Hz the fixed setting allows, so an expression cannot ask for a carrier the timer cannot make.
    Minimum On Time
    outputs.output[].min_on_ms
    Range: 0 to 65535
    Default: 0
    Units: ms    		 Once on, stay on at least this long whatever the conditions say. A relay that chatters is a relay that welds, and a compressor or a pump wants a floor under its cycle time.
    Minimum Off Time
    outputs.output[].min_off_ms
    Range: 0 to 65535
    Default: 0
    Units: ms    		 Once off, stay off at least this long before it may come on again. The other half of anti-chatter, and on an air-conditioning compressor it is a hardware requirement rather than a nicety.
    Maximum On Time
    outputs.output[].max_on_ms
    Range: 0 to 65535
    Default: 0
    Units: ms    		 A hard limit on how long it may stay on in one go; 0 = no limit. This is what makes a starter output safe: cranking is bounded, and the output releases whatever the button says. After it trips, the Re-Arm Delay must pass before it can run again.
    Re-Arm Delay
    outputs.output[].rearm_ms
    Range: 0 to 65535
    Default: 0
    Units: ms    		 How long the slot is locked out after the maximum on time trips. For a starter it is the motor cooling down; for anything else it is a rate limit on a condition that keeps asking.
    If Unanswerable
    outputs.output[].on_invalid
    Range: one of: Off, On, Hold
    Default: Off    		 What to do when the condition cannot be evaluated — a channel it names is dead, absent or never assigned. The right answer is not the same for every load, which is why it is a setting: a cooling fan should fail ON, a starter and a fuel pump must fail OFF, and something that is merely inconvenient can HOLD its last state. A condition that cannot be answered is not the same as one that answered no.
    Value From
    outputs.output[].value_source
    Range: one of: Candidates, Table, Fixed, Expression
    Default: Candidates    		 Where the commanded value comes from while the slot is on. CANDIDATES arbitrates the bus signals below, which is what a slot driven by a module wants. TABLE interpolates this slot's own duty map against the two channels you point its axes at — a fan against coolant, a steering pump against road speed, a fuel pump against demand. FIXED is a constant, which is what most relays and many pumps actually need. EXPRESSION computes it: the duty expression's NUMBER is the command, so a duty can be arithmetic over any channels rather than a surface somebody has to draw.
    Fixed Value
    outputs.output[].fixed_x10
    Range: -100.0 to 200.0
    Default: 100.0
    Units: %    		 The constant commanded while the slot is on, when the value source is Fixed. 100% is full on — for a digital output anything above the switching threshold is simply "on", so the default suits a relay as it stands.

    Parameter A
    outputs.output[].param_a
    Range: -2000000.000 to 2000000.000
    Default: 0.000    		 The first number the slot's template asks for — prime seconds, a fan's switch-on temperature, a starter's crank limit. What it means is written on the wizard that set it; the condition reads it by name.
    Parameter B
    outputs.output[].param_b
    Range: -2000000.000 to 2000000.000
    Default: 0.000    		 The second number the slot's template asks for.
    Parameter C
    outputs.output[].param_c
    Range: -2000000.000 to 2000000.000
    Default: 0.000    		 The third number the slot's template asks for.
    Parameter D
    outputs.output[].param_d
    Range: -2000000.000 to 2000000.000
    Default: 0.000    		 The fourth number the slot's template asks for.
    Name
    outputs.output[].name    		 What this output IS, in your words — "Left Fan", "Pump A", "Starter". A pin name says where it is wired, not what is on the end of it, and the name travels to the pages, the datalog and the fault text.
    Signal
    outputs.output[].cand[4].sig    		 The bus signal this candidate contributes. 255 leaves the slot unused. A candidate whose signal is not valid right now is skipped entirely rather than treated as zero — which is the difference between a module that has nothing to say and a module asking for nothing.
    Role
    outputs.output[].cand[4].role
    Range: one of: Primary, Limit, Override    		 How this candidate participates. PRIMARY makes the request — several primaries are combined by the output's primary policy. LIMIT clamps the result DOWN, and the lowest valid limit wins, so any module may hold the output back but none can push it up. OVERRIDE vetoes: the first valid one replaces everything above it. The precedence is fixed (primary, then limit, then override), so the role alone decides authority — order in the list does not.
