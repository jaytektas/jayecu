    Sensor types¶

    Every sensor has a type: what it measures, in which units, over which range, how often it is read, and which checks it can run (chapter 17). The ECU always works in these units; the studio can show others (Preferences ▸ Units).

    Type Units Range Read at Checks
    temperature C -40 to 300 5 Hz raw_min, raw_max, operating_min, operating_max
    exhaust_temperature C -40 to 1500 5 Hz raw_min, raw_max, operating_min, operating_max
    pressure kPa -101.3 to 3000 100 Hz raw_min, raw_max, operating_min, operating_max
    percent % -100 to 200 200 Hz raw_min, raw_max, operating_min, operating_max
    position deg -720 to 720 100 Hz raw_min, raw_max, operating_min, operating_max
    level % 0 to 100 2 Hz raw_min, raw_max, operating_min, operating_max
    lambda λ 0.5 to 1.5 20 Hz raw_min, raw_max, operating_min, operating_max
    flow g/s 0 to 1000 50 Hz raw_min, raw_max, operating_min, operating_max
    composition % 0 to 100 5 Hz operating_min, operating_max
    frequency Hz 0 to 100000 50 Hz operating_min, operating_max, max_derivative
    switch bool 0 to 1 50 Hz stuck
    narrowband V 0 to 5 50 Hz raw_min, raw_max, operating_min, operating_max
    voltage V 0 to 32 20 Hz raw_min, raw_max, operating_min, operating_max
    multi_switch 0 to 15 50 Hz raw_min, raw_max, stuck
    high_pressure kPa 0 to 30000 20 Hz raw_min, raw_max, operating_min, operating_max
