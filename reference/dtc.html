    Trouble codes¶

    Every trouble code this firmware's definition names, with the studio's description and the Status Lamps category that lights for it. How codes work — severity, active and stored, clearing — is chapter 44.

    Codes P0xxx are the standard OBD-II ones; P1xxx are this ECU's own. A sensor's own checks (out of range, not assigned …) use the sensor's standard codes where there are any, and codes in P1000–P15FF where there are none.
